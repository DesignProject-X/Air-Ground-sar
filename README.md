# Air-Ground-Collaborative-Exploration-Target-Rescue-Via-Embodied-Gateway-and-Dual-Agent-System
Overview
This project implements a closed-loop air-ground collaborative system for search and rescue in unknown environments. A UAV performs aerial reconnaissance and 2D mapping, while a ground robot uses the resulting map to navigate autonomously to a target — all orchestrated by a three-layer architecture with no human intervention after the initial command.
